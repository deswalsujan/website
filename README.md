# Website

Personal/marketing site, migrated from static HTML into [Astro](https://astro.build).

## Running locally

```sh
npm install
npm run dev
```

The site will be available at `localhost:4321`.

## Deployment

This site deploys to **Cloudflare Workers**.

See `PLAN.md` for the current migration checklist and key decisions, and `AGENTS.md` (aliased as `CLAUDE.md`) for the working agreement used in every session.
